# TrulyHer

An AI-powered journaling companion that helps women in STEM notice, understand, and gently navigate imposter syndrome.

## Overview

TrulyHer transforms short daily reflections into personalized insights, supportive AI messages, and clear visual trends. It's designed for women in tech who want a calmer, more confident relationship with learning, work, and self-growth.

More than 80% of female executives report experiencing imposter syndrome at some point in their careers — often silently. TrulyHer helps break that silence.

## Why I Built This

As a woman in STEM, I've felt imposter syndrome more times than I can count — the quiet doubt, the "I'm not good enough," the feeling that everyone else has it figured out except me. It slowed me down, made me second‑guess myself, and sometimes kept me from opportunities I was fully capable of taking.

I built TrulyHer because I don't want other women to feel alone in that experience.

This project is my way of turning something painful into something supportive. I wanted to create a tool that listens without judgment, reflects patterns you might not notice, and offers gentle, actionable steps toward confidence. Not perfection — just progress. If TrulyHer helps even one woman feel seen, understood, and a little more grounded, then it's doing its job.

## Features

- AI-powered journaling with personalized encouragement
- Pattern detection for imposter-syndrome-related thoughts and behaviors
- Mood & stress tracking with visual trend insights
- Micro-actions to break procrastination loops and build confidence
- Local data storage for privacy
- Motivational poster export (via html2canvas)

## Tech Stack

- React
- Tailwind CSS
- Node.js (local development)
- Create React App
- Optional Gemini API integration (via environment variable)

## Getting Started

git clone https://github.com/ErinGu0/TrulyHer.git
cd TrulyHer
npm install
npm start

Add your Gemini API key in `.env`:

REACT_APP_GEMINI_API_KEY=your_key_here

## How It Helps

TrulyHer supports women in STEM by:

- Naming what you're feeling so it loses power
- Translating emotions into clear, evidence-based insights
- Offering tiny, doable steps that build confidence over time
- Showing progress through visual trends you might not notice day to day
- Using a tone that is intentionally warm, clear, and non-technical
